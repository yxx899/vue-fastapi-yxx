1  项目概述
1.1  项目定位
对标企业内部 AI 问答 Copilot 的企业级智能知识库平台，属于 AI 应用开发工程师的真实业务项目。系统供多家企业（租户）独立使用，租户之间数据、知识库、文档完全隔离。租户内部由管理员维护部门、用户、知识库并上传文档，普通员工在自身权限范围内检索文档、提问，并获得带溯源引用的 AI 回答。
1.2  技术栈
后端：FastAPI、SQLAlchemy、Pydantic、LangChain / LangGraph。
大模型与向量：通义千问（Qwen）、BGE 嵌入模型、Chroma 向量库。
前端：Vue3 + Element Plus。
数据库：MySQL。
1.3  核心特性
多租户隔离：所有业务表与向量元数据均携带 tenant_id，检索强制过滤，杜绝跨租户访问。
细粒度 RBAC 权限：平台超管 / 租户管理员 / 普通员工三层角色，知识库支持按用户或部门授权（只读 / 管理）。
RAG 检索增强：文档解析、分块、BGE 向量化入库，问答时召回片段并拼接上下文，降低幻觉。
文档增量入库：新增文档单独入库，删除同步清理向量，更新采取删旧向量后重新切片。
流式对话：SSE 流式输出，回答附带原文溯源。
问答审计：全量问答日志留痕，支持反馈与统计看板，满足企业合规要求。
1.4  总体业务需求
1. 平台可为多家企业（租户）独立开通账号使用，租户之间文档、向量、对话数据互相隔离，不可互相访问。
2. 每个租户内部可维护自己的员工、部门、知识库与文档。
3. 租户员工只能访问被分配权限的知识库，并在权限范围内上传文档、提问、查看对话历史。
4. 支持 RAG 增强问答，回答附带原文溯源，降低大模型幻觉。
5. 所有问答行为留日志，支持审计追溯，满足企业合规要求。
6. 文档解析、向量化异步执行，避免上传超时。
7. 问答支持 SSE 流式输出，体验类似 ChatGPT。
2  角色需求
2.1  平台超级管理员（平台级，不属于任何租户）
功能：
租户新增、启用、停用、编辑租户信息。
设置租户资源限额：最大知识库数量、最大文档总数、单文件大小上限。
查看全部租户基础统计信息。
只能看到租户元数据，无法查看租户内部文档、对话内容。
注意事项：超级管理员使用独立登录入口，不混入租户登录体系；禁止越权读取租户业务数据。
2.2  租户管理员（每个企业内部管理员）
功能：
本租户内新增、编辑、删除员工账号，重置员工密码。
本租户内部门管理：新增、编辑、删除部门及上下级部门。
本租户内创建、编辑、停用、删除知识库。
给用户 / 部门分配知识库权限（只读 / 管理）。
查看并导出本租户全部问答日志。
查看租户内统计看板：知识库数量、文档数量、提问量、点赞反馈统计。
查看文档解析失败记录，并可重新触发解析。
注意事项：只能操作当前登录对应的 tenant_id 下的数据；不能管理其他租户；不能修改租户资源限额（限额由平台超管控制）。
2.3  普通员工用户
功能：
登录、修改本人密码。
查看自己有权限的知识库列表。
在有权限的知识库内上传文档。
查看、删除自己上传的文档（具备知识库管理权限的用户可删除所有人文档）。
新建对话会话，选择一个或多个知识库提问。
流式接收 AI 回答，查看回答附带的引用溯源片段。
对 AI 回答点赞 / 点踩反馈。
查看本人全部对话会话与历史消息，删除自己的会话。
注意事项：打开知识库、提问前，后端必须校验该用户是否拥有该知识库权限；没有权限的知识库在前端直接隐藏，不得展示。
3  模块功能明细
3.1  租户管理模块
功能：
新增租户：企业名称、联系人、联系电话、资源配额、过期时间。
租户列表查询、筛选、分页。
修改租户基础信息。
启用 / 禁用租户（禁用后租户内所有用户无法登录）。
租户资源校验：新建知识库、上传文档时判断是否超过限额。
注意事项：所有业务表必须携带 tenant_id，作为隔离核心字段；Chroma 向量每条元数据存入 tenant_id + kb_id，检索时强制过滤；禁用租户后，禁止该租户所有写入操作（上传文档、新建对话）。
3.2  用户、部门与权限（RBAC）模块
功能：
用户：新增、编辑、删除，密码加密存储（bcrypt），登录 JWT 鉴权。
部门：树形部门管理。
知识库权限绑定：支持绑定单个用户或整个部门。
权限类型：只读权限（查看、提问，不能上传/删除文档、不能分配权限）；管理权限（文档上传、删除、查看文档列表、分配该知识库权限）。
登录中间件：解析 token，自动携带当前 tenant_id、user_id、角色信息。
注意事项：每次查询知识库、文档、问答接口统一走权限拦截校验；同一用户可拥有多个知识库、多种权限；不能出现 A 租户用户查到 B 租户用户数据。
3.3  知识库管理模块
功能：
创建知识库：名称、描述、是否租户内公开。
知识库列表分页查询。
修改知识库名称、描述。
启用 / 停用知识库（停用后不能选择该知识库提问）。
删除知识库：删除知识库记录 + 删除该知识库下全部文档 + 清理 Chroma 内对应全部向量。
权限分配页面：给用户 / 部门分配该知识库权限。
注意事项：知识库删除属级联删除，向量库同步清理，防止垃圾向量残留；“租户内公开”即租户内所有员工默认拥有只读权限，无需单独分配。
3.4  文档管理模块
功能：
支持文件上传类型：PDF、Markdown、TXT、Word。
文件存储（本地文件或对象存储）。
上传后异步任务：文档解析 → 文本清洗（去除页眉页脚、多余空行）→ 文本分块 → BGE 向量化 → 写入 Chroma。
文档状态：待解析 / 解析成功 / 解析失败。
文档列表：文件名、文件大小、上传时间、解析状态。
删除文档：删除文件记录、物理文件、Chroma 内该文档对应的全部向量。
重新解析：解析失败文档支持重新触发异步解析。
注意事项：异步任务不要阻塞接口，简单版本使用 BackgroundTasks，正式版本推荐 Celery；文档切片策略（块大小、重叠大小）需可调并记录参数；记录当前文档对应的全部 vector_id，删除时据此精准删除向量（重点难点）；校验文件类型与大小，防止恶意大文件上传；解析异常捕获并记录失败原因供管理员查看。
3.5  对话与 RAG 问答核心模块
功能：
对话会话：新建会话、会话列表、修改会话标题、删除会话。
消息持久化：用户消息、AI 回答、引用溯源信息、反馈标记。
SSE 流式问答接口。
RAG 检索链路：权限校验 → 问题向量化 → 指定 tenant+kb 范围召回向量片段 → 拼接上下文 Prompt → 调用 Qwen 流式返回。
回答附带溯源：返回文档名称、原文片段。
回答反馈：点赞、点踩，存入消息记录。
注意事项：
检索向量时必须带上 tenant_id + kb_id 过滤元数据，这是多租户安全最核心的点，漏掉会直接造成跨租户数据泄露。
控制召回 TopK 数量，上下文长度不能超过大模型上下文窗口。
Prompt 区分系统提示词、检索上下文、用户问题，单独封装。
SSE 接口要处理前端断连，避免后台持续无效调用大模型。
溯源只返回片段，不返回完整文档，保护文档内容。
大模型调用异常、超时需捕获，前端友好提示。
3.6  审计、日志与统计看板模块
功能：
问答日志记录：提问内容、回答内容、用户、租户、知识库、引用文档、时间、反馈。
日志分页查询，按时间 / 用户筛选，导出日志。
租户看板统计指标：知识库总数、文档总数、今日提问次数、历史总提问次数、好评数量、差评数量。
文档解析失败统计。
注意事项：日志不可删除（基础版本要求；企业正式版会做日志归档）；日志仅租户管理员、超管可查看，普通员工只能看自己的对话，不能查看他人问答日志。
4  全局通用注意事项
4.1  安全类
JWT 过期机制，token 防篡改。
所有入参用 Pydantic 校验，防止 SQL 注入、路径遍历。
禁止前端传 tenant_id，tenant_id 一律从登录 token 解析获取，前端无权控制。
文件上传路径隔离，限制可上传后缀，禁止执行类文件。
接口统一权限中间件，不逐接口手写权限判断，避免遗漏。
4.2  RAG 与向量库工程类
Chroma 为内存 + 文件型向量库，不适合高并发生产；项目中注明本项目采用 Chroma 做演示向量库，生产可替换 Milvus / FAISS。
文档更新策略：更新文档 = 删除旧向量 → 重新切片入库，不原地修改向量。
记录向量 ID 映射关系，否则删除文档时无法精准清理向量，向量库会越积越大。
幻觉控制：依靠溯源引用与 Prompt 约束，明确告知模型只能使用检索到的内容回答。
4.3  业务边界类
租户限额判断：新建知识库、上传文档前校验，超限直接拒绝。
知识库停用后，不能选中该知识库发起问答。
角色不能越权：普通员工不能访问审计日志、不能分配权限。
4.4  体验与稳定性类
异步解析状态实时轮询，前端展示解析进度 / 失败提示。
流式接口超时处理、大模型接口异常捕获。
知识库列表、文档列表、会话列表、审计日志全部做分页，防止数据量大时接口卡死。
